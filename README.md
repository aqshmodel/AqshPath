# Aqsh path

「Big Rocks理論」「衝動制御」「コンフォートゾーン拡大」「習慣化」のコア機能に加え、「シャドウワーク」「認知行動療法ジャーナル」を搭載。日々の行動に哲学的な指針を与える「アルバートの教訓」を統合し、科学と哲学の両面から自己変革をサポートする究極のパートナーです。

このアプリケーションは、最先端のAI技術（Google Gemini API）を活用し、ユーザー一人ひとりにパーソナライズされたフィードバックを提供することで、自己成長の旅を強力に支援します。

## ✨ 主な機能

このアプリは、自己変革を多角的にサポートするための豊富な機能を備えています。

### 🏠 ホームタブ: 人生のビジョンを明確にする

-   **Big Rocks理論の実践**: 人生で最も重要な目標（Big Rocks）をビジョンとして設定し、日々の行動をそれに集中させます。
    -   **ビジョンボード**: タイトル、インスピレーション画像（3枚まで）、アファメーションを設定して、目標を視覚化します。
    -   **コミットメント契約**: 自分との約束として「ご褒美」と「罰」を設定し、モチベーションを高めます。
    -   **進捗管理**: 「未着手」「進行中」「完了」のステータスで、ビジョンへの進捗を管理できます。
-   **今日の教訓**: 哲学者アルバートの教えから、毎日ランダムで一つが表示され、日々の行動に哲学的な指針を与えます。
-   **価値観エディタ**: 自分が人生で最も大切にしている価値観を定義し、いつでも編集できます。これはAIコーチの分析にも利用されます。

### 📋 習慣タブ: 良い習慣を形成し、悪い習慣を断ち切る

-   **マイ習慣 (良い習慣の形成)**
    -   **習慣ビルダー**: 複数の活動ブロック（タスクと所要時間）を組み合わせて、自分だけのカスタムルーティンを作成できます。
    -   **テンプレート**: 「朝の生産性習慣」「夜のリラックス習慣」など、すぐに始められるテンプレートを用意。
    -   **ストイックモード**: 決めた時間に必ず実行するための厳格なリマインダー機能です。
    -   **習慣プレイヤー**: 作成した習慣を一つずつ順番に実行するためのタイマー機能。
    -   **勝利の記録**: 「昨日の自分に勝った」小さな成功を記録し、自己効力感を高めます。
-   **成長習慣 (7つの習慣)**
    -   **自己評価と可視化**: 7つの重要な成長習慣（期待を超える、信頼性、成長志向など）について自己評価を行い、そのバランスをレーダーチャートで視覚的に確認できます。
    -   **今日のフォーカス**: 毎日、特に意識する習慣と具体的な行動（誓約）を設定し、達成を記録します。
    -   **インパクトログ**: 自分の行動が他者や自分自身に与えたポジティブな影響を記録します。「今日のフォーカス」達成時に記録を促されます。
-   **悪習慣の克服**
    -   **悪習慣の定義**: やめたい習慣、そのきっかけ（トリガー）、代わりに行うべき行動を登録します。
    -   **日々の記録**: 悪習慣の誘惑に「抵抗できた」か「屈した」かを毎日記録します。
    -   **成功率の追跡**: 記録に基づいて成功率が自動で計算され、進捗を確認できます。

### ⚡ アクションタブ: 「今」の行動を変える

-   **衝動制御**
    -   **衝動遅延タイマー**: 衝動的な行動を遅らせるためのタイマー。「後悔最小化フレームワーク」に基づいた問いかけが、冷静な判断を助けます。
    -   **自己信頼スコア**: 自分との約束を守ることで上下するスコア。衝動に打ち勝つとスコアが上がり、自己信頼の指標となります。
    -   **衝動ログ**: タイマー使用の結果（成功／失敗）を記録し、過去の傾向を振り返ることができます。
-   **チャレンジ (コンフォートゾーン拡大)**
    -   **チャレンジの設定**: 不快感レベルを設定して、自分の快適領域（コンフォートゾーン）を超えるための挑戦を定義します。
    -   **成長マップ**: チャレンジを達成することでコンフォートゾーンが広がっていく様子を視覚的に確認できます。
    -   **振り返り機能**: チャレンジ完了後に、実際に感じた不快感、達成感、そして得られた学びを記録します。
-   **集中タイマー (ポモドーロ)**
    -   **ポモドーロ・テクニック**: 集中と休憩のサイクルを繰り返すことで、生産性を最大化します。
    -   **カスタマイズ可能**: 集中時間と休憩時間は自由に設定できます。

### 🧠 内省タブ: 自分を深く理解する

-   **ジャーナル**
    -   **3種類のジャーナル**:
        1.  **思考改善ジャーナル (CBT)**: 認知行動療法に基づき、出来事(A)→自動思考(B)→結果(C)→反論(D)→新しい考え(E)の5ステップで思考の癖を修正します。
        2.  **フリージャーナル**: 頭に浮かんだことを自由に書き出すためのスペース。
        3.  **インパクトログ**: フリージャーナル内でも記録可能で、ポジティブな影響の記録ができます。
    -   **AIコーチ**: 記録されたジャーナル、習慣、悪習慣のデータを総合的に分析し、パーソナライズされたフィードバックやアドバイスを提供します。
-   **シャドウワーク**
    -   **パスコード保護**: 内密な記録を守るための4桁のパスコードロック機能。
    -   **30日間のプログラム**: 心理学者ユングの「シャドウ」の概念に基づき、自分自身の隠された側面に光を当てるためのプログラム。AIが毎日、自己探求を深めるための問いを生成します。
    -   **信念ライブラリ**: シャドウワークを通じて発見した、自分を縛る「思い込み」を、力になる「新しい信念」に書き換えて管理します。
-   **週次レビュー**
    -   **AIによる自動生成**: 1週間の全活動（習慣、チャレンジ、ジャーナルなど）をAIが分析し、ハイライト、成長の機会、来週へのアクションプランをまとめた詳細なレビューを生成します。

## 🚀 ローカルでの実行方法

このアプリケーションをローカル環境で実行するための手順は以下の通りです。

### 前提条件

-   Node.js (v18以降を推奨)
-   npm (Node.jsに同梱)
-   Google Gemini APIキー:AIzaSyAuy_c1Ly_qS_d8IsWZVai2KcmFm1rQCpY

### インストールと実行

1.  **依存関係をインストールする**
    このプロジェクトは、必要なすべての依存関係が `index.html` の `importmap` で定義されているため、`npm install` を実行する必要はありません。

2.  **APIキーを設定する**
    AI機能（AIコーチ、シャドウワークの質問生成、週次レビュー）を利用するには、Google Gemini APIキーが必要です。お使いの実行環境で環境変数 `API_KEY` を設定してください。

3.  **開発サーバーを起動する**
    お使いのローカル開発サーバーを使用して、プロジェクトのルートディレクトリをサーブしてください。例えば、`serve` パッケージを使用する場合：
    ```bash
    npx serve .
    ```
    これにより、開発サーバーが起動し、指定されたURL（通常は `http://localhost:3000`）をブラウザで開くとアプリケーションが表示されます。

### データについて

このアプリケーションのデータは、すべてブラウザの `localStorage` に保存されます。サーバーサイドのデータベースは使用していません。そのため、異なるブラウザやシークレットモードで開くとデータは共有されず、ブラウザのキャッシュをクリアするとデータが失われる可能性がありますのでご注意ください。
